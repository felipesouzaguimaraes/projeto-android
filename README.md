Este projeto consiste em um site jornalístico completo e focado em tecnologia, que conta a história e as curiosidades por trás do surgimento do mascote do **Android** (o Bugdroid). O projeto foi desenvolvido como o **Desafio 10 (Módulo 2)** do renomado curso de HTML5 e CSS3 do **Curso em Vídeo**, ministrado pelo professor **Gustavo Guanabara**.

O grande objetivo deste desafio foi consolidar conceitos fundamentais de design web, tipografia personalizada, harmonização de cores e a implementação de layouts fluidos e semânticos.

## 🎨 Conceitos Visuais e Funcionalidades

O site foi estruturado seguindo boas práticas de identidade visual e experiência do usuário:

| Aspecto Técnico | Implementação Aplicada |
| :--- | :--- |
| **Arquitetura Semântica** | Uso rigoroso de tags do HTML5 como `<header>`, `<nav>`, `<main>`, `<article>`, `<aside>` e `<footer>` para melhor indexação e acessibilidade. |
| **Tipografia Avançada** | Importação de fontes externas e locais via `@font-face` (fontes *Idroid* e *Bebas Neue*) para criar contraste profissional entre títulos e textos. |
| **Imagens Responsivas** | Uso da tag `<picture>` combinada com `<source>` para carregar imagens otimizadas de tamanhos diferentes baseadas na largura da tela (como os blocos dos Dandroids). |
| **Paleta de Cores Temática** | Estilização baseada em tons de verde oliva e gradientes modernos que remetem diretamente à identidade clássica do sistema operacional Android. |

## 📂 Estrutura de Arquivos do Repositório

O projeto está organizado de maneira limpa para facilitar a manutenção dos códigos:

* `index.html` — Código fonte principal com toda a marcação e conteúdo semântico do artigo.
* `estilo/`
  * `style.css` — Folha de estilo responsável por toda a identidade visual, sombras, cantos arredondados e gradientes do site.
* `fontes/` — Arquivos locais das fontes personalizadas utilizadas no layout do projeto.
* `imagens/` — Banco de imagens completo contendo ilustrações, ícones e variações de tamanho para a responsividade.

## 🚀 Como Executar o Projeto Localmente

Por ser um projeto puramente Front-End estático, você pode rodá-lo instantaneamente:

1. Baixe os arquivos ou clone este repositório.
2. Abra a pasta principal do projeto.
3. Dê um duplo clique no arquivo `index.html` para executá-lo em seu navegador padrão.
